# Тест-план проекта B2C Telecom Automation

В данном документе описаны тест-кейсы для проверки функционала Личного кабинета B2C (Web и Mobile), а также API.
Часть тестов автоматизирована, часть выполняется вручную (Manual QA).

## Модуль 1: Авторизация (UI)

| ID | Название теста | Шаги | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- | :--- |
| **TC-001** | Успешный вход (standard_user) | 1. Открыть сайт.<br>2. Ввести логин `standard_user`.<br>3. Ввести пароль `secret_sauce`.<br>4. Нажать Login. | Открывается главный экран ЛК (Dashboard). | **Automated** (UI) |
| **TC-002** | Вход заблокированного пользователя | 1. Ввести логин `locked_out_user`.<br>2. Ввести пароль.<br>3. Нажать Login. | Появляется сообщение "Epic sadface: Sorry, this user has been locked out." | **Automated** (UI) |
| **TC-003** | Вход с неверным паролем | 1. Ввести логин `standard_user`.<br>2. Ввести неверный пароль.<br>3. Нажать Login. | Появляется сообщение "Username and password do not match". | **Manual** |

| :--- | :--- | :--- | :--- | :--- |

## Условные обозначения
* **Automated** — тест покрыт автотестом (находится в репозитории).
* **Manual** — тест требует ручной проверки (например, из-за сложности UI или отсутствия API).
